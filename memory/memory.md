>   - `/remember <内容>`        添加一条记忆（自动分类）

>   - `/forget <关键词>`         删除包含关键词的记忆条目
>   - `/refresh_memory`          从近期对话中提取偏好并更新（手动触发）
>   - `/profile`                 查看当前声明性记忆
