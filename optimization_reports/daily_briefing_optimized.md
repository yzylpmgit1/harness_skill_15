# 每日简报技能 · 工作流

## 触发条件
用户表达获取每日综合信息意图时激活，包括：简报/日报/晨报/早报/今日概览/每日概况，或同时提及天气和股票。

## 工作流程

### 1. 提取关键信息
- **城市**：用户指定则使用；未指定则询问
- **股票**：用户指定则使用；未指定则询问
- **时间**：默认当天

### 2. 调用工具（固定顺序）
1. **weather**：`{"city": "城市名称"}`
2. **stock_quote**：`{"stock": "股票名称", "period": "daily"}`

### 3. 生成简报
格式如下：
```
【每日简报】
日期：YYYY年M月D日

一、天气概况
城市/天气/温度/湿度/风速 + 出行建议

二、股市行情
股票/最新价格/涨跌幅 + 投资参考

三、今日总结
综合出行和投资建议
```

### 4. 兜底处理
| 情况 | 处理 |
|------|------|
| 未指定城市/股票 | 主动询问 |
| 工具调用失败 | 告知用户稍后重试 |
| 股票不支持 | 提供支持列表 |

## 工具参数
| 工具 | 参数 | 说明 |
|------|------|------|
| weather | `{"city": "城市"}` | 查询实时天气 |
| stock_quote | `{"stock": "股票", "period": "daily"}` | 查询日线行情，period 默认 daily |

## 回答规范
1. 结构清晰：含天气和股市两大部分
2. 数据准确：必须来自工具返回，禁止编造
3. 语言简洁：突出要点
4. 提供建议：天气→出行建议；股票→投资参考
5. 附带日期
6. 股票部分附免责声明："以上股票分析基于历史数据，不构成投资建议。"
7. 温度保留1位小数（°C）；涨跌幅保留2位小数（%）
8. 未指定城市/股票时主动询问，不得随意选择
9. 工具失败时如实告知并提供建议

## 注意事项
- 两个工具必须都调用，不可只调一个
- 简报仅供参考，不构成投资或出行决策依据
- 用户需更多详情时，建议使用专项技能
- 保持客观中立，不做主观判断
