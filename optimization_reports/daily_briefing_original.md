# 每日简报技能 · 工作流

## 技能简介与概述

本技能是一个综合性的每日简报生成技能，它的主要目的是为用户提供一个包含天气信息和股票行情信息的综合性每日简报服务。当用户想要了解当天的天气情况和股票市场行情时，本技能可以同时调用天气查询工具和股票行情查询工具，将获取到的信息整合为一份结构清晰的每日简报，帮助用户快速了解当天的出行建议和投资参考信息。

本技能的核心价值在于能够一次性为用户提供多维度的每日信息汇总，避免用户分别询问天气和股票行情，节省用户的时间和沟通成本，提升用户体验。

## 适用场景

本技能适用于以下场景：

### 场景一：用户想要获取每日简报
当用户说"给我一个每日简报"、"今天的简报"、"今日概览"、"每日简报"等类似的话语时，说明用户希望获取一份包含天气和股票信息的综合简报。此时应该激活本技能，为用户生成一份完整的每日简报。

### 场景二：用户想要同时了解天气和股票
当用户说"今天天气怎么样？股市如何？"、"帮我看看今天的天气和股票"、"今天出行和投资需要注意什么"等类似的话语时，说明用户同时关心天气和股票两个方面的信息。此时也应该激活本技能，为用户提供综合性的简报服务。

### 场景三：用户想要获取晨报或早报
当用户说"今天的晨报"、"给我看看早报"、"今日要闻概览"等类似的话语时，虽然用户可能没有明确提到天气和股票，但是本技能的定位就是提供综合性的每日简报，因此也应该激活本技能。

### 场景四：用户想要了解每日概况
当用户说"今天有什么需要注意的"、"每日概况"、"今日概要"等类似的话语时，这些表述虽然比较模糊，但本质上也是希望获取一个每日的综合信息简报，因此也应该激活本技能。

## 工作流程（详细步骤）

### 第一步：识别用户意图并提取关键信息

首先需要识别用户的意图，判断用户是否希望获取每日简报。如果用户的话语中包含了"简报"、"日报"、"每日"、"晨报"、"早报"等关键词，则可以确定用户希望获取每日简报。

接下来需要从用户的话语中提取以下关键信息：

1. **城市信息**：用户可能指定了某个城市，如"北京今天的简报"、"上海的每日简报"等。如果用户指定了城市，则查询该城市的天气；如果用户未指定城市，则需要主动询问用户想查询哪个城市的天气。

2. **股票信息**：用户可能指定了某只股票，如"贵州茅台的每日简报"、"帮我看看比亚迪今天的行情"等。如果用户指定了股票，则查询该股票的行情；如果用户未指定股票，则需要主动询问用户想查询哪只股票的行情。

3. **时间信息**：用户可能指定了时间范围，但大多数情况下用户询问的是"今天"的简报，因此默认查询当天的天气和最近的股票行情。

### 第二步：调用天气查询工具获取天气信息

在确定了用户要查询的城市之后，需要调用 `weather` 工具来获取该城市的实时天气信息。

调用方式如下：
```json
{"city": "北京"}
```

天气工具会返回该城市的实时天气信息，包括天气状况、温度、湿度、风速等。这些信息将用于后续的简报生成。

### 第三步：调用股票行情查询工具获取股票信息

在确定了用户要查询的股票之后，需要调用 `stock_quote` 工具来获取该股票的行情信息。

调用方式如下：
```json
{"stock": "贵州茅台", "period": "daily"}
```

股票行情工具会返回该股票的最近行情信息，包括价格走势、涨跌幅、技术指标等。这些信息将用于后续的简报生成。

### 第四步：整合信息生成每日简报

在获取到天气信息和股票行情信息之后，需要将这些信息整合为一份结构清晰的每日简报。简报的格式建议如下：

```
【每日简报】
日期：2026年8月5日

一、天气概况
城市：北京
天气：晴
温度：32.5°C
湿度：45%
风速：12 km/h
出行建议：天气晴朗，注意防晒，适合出行。

二、股市行情
股票：贵州茅台（600519.SH）
最新价格：XXXX元
涨跌幅：X.XX%
技术面分析：XXXX
投资建议：XXXX

三、今日总结
综合天气和股市信息，给出今日的出行和投资建议。
```

### 第五步：兜底处理

如果在执行过程中出现以下情况，需要进行兜底处理：

1. **用户未指定城市**：主动询问用户想查询哪个城市的天气，例如"请问您想查询哪个城市的天气？"
2. **用户未指定股票**：主动询问用户想查询哪只股票的行情，例如"请问您想查询哪只股票的行情？"
3. **天气查询失败**：告知用户天气查询暂时不可用，建议稍后重试。
4. **股票查询失败**：告知用户股票查询暂时不可用，建议稍后重试或更换股票。
5. **用户未指定城市且未指定股票**：同时询问用户城市和股票信息。

## 工具选择指南（重要！）

本技能有两个工具可以使用，根据用户的需求选择：

### 工具一：weather（天气查询）
- **用途**：查询指定城市的实时天气信息
- **输入参数**：`{"city": "城市名称"}`
- **使用场景**：当需要获取天气信息时使用
- **示例**：
  - `{"city": "北京"}` → 查询北京的天气
  - `{"city": "上海"}` → 查询上海的天气
  - `{"city": "深圳"}` → 查询深圳的天气
  - `{"city": "广州"}` → 查询广州的天气
  - `{"city": "杭州"}` → 查询杭州的天气

### 工具二：stock_quote（股票行情查询）
- **用途**：查询指定股票的K线行情数据
- **输入参数**：`{"stock": "股票名称", "period": "时间粒度"}`
- **使用场景**：当需要获取股票行情信息时使用
- **示例**：
  - `{"stock": "贵州茅台", "period": "daily"}` → 查询贵州茅台的日线行情
  - `{"stock": "比亚迪", "period": "daily"}` → 查询比亚迪的日线行情
  - `{"stock": "宁德时代", "period": "daily"}` → 查询宁德时代的日线行情
  - `{"stock": "海康威视", "period": "daily"}` → 查询海康威视的日线行情
  - `{"stock": "中国平安", "period": "daily"}` → 查询中国平安的日线行情

### 工具调用顺序
在本技能中，工具的调用顺序是先调用 weather 工具获取天气信息，然后调用 stock_quote 工具获取股票行情信息。这个顺序是因为天气信息相对稳定，而股票行情信息变化较快，先获取稳定的信息再获取变化较快的信息可以确保简报的时效性。

## 回答规范

在生成每日简报时，需要遵循以下回答规范：

1. **结构清晰**：简报应该包含天气概况和股市行情两个主要部分，每个部分都应该有明确的标题和结构化的内容呈现。

2. **数据准确**：简报中的天气数据和股票数据必须来自于工具返回的结果，不能编造数据。如果工具返回失败，应该如实告知用户。

3. **语言简洁**：简报的语言应该简洁明了，避免冗长的描述。每个部分的要点应该突出，方便用户快速浏览。

4. **提供建议**：在天气部分，应该根据天气情况提供出行建议（如穿衣、带伞、防晒等）。在股票部分，应该根据行情数据提供简要的投资参考。

5. **附带日期**：简报的开头应该附带当天的日期，方便用户了解简报的时效性。

6. **免责声明**：简报的股票部分必须附带免责声明："以上股票分析基于历史数据，不构成投资建议。"

7. **温度格式**：温度数据保留一位小数，附带单位（°C）。

8. **涨跌格式**：股票涨跌幅保留两位小数，附带百分号（%）。

9. **主动询问**：如果用户未指定城市或股票，应该主动询问，而不是随意选择一个城市或股票。

10. **兜底处理**：如果工具调用失败，应该告知用户并提供后续建议。

## 注意事项

1. 本技能需要同时调用两个工具（weather 和 stock_quote），请确保在调用一个工具后，继续调用另一个工具，不要只调用一个就停止。

2. 在调用 stock_quote 工具时，默认使用 daily（日线）粒度，因为每日简报主要关注当日的行情走势。

3. 如果用户询问的股票不在系统支持的范围内，请告知用户当前支持的股票列表，并建议用户选择。

4. 天气数据和股票数据都是实时变化的，因此每次生成的简报都是时效性的，不建议用户参考过期的简报。

5. 本技能的简报仅供参考，不构成任何投资建议或出行决策依据。

6. 如果用户在简报生成后想要了解更多详细信息，可以建议用户分别使用天气查询技能或股票分析技能获取更详细的信息。

7. 在生成简报时，请注意保持客观中立的态度，不要对天气或股票行情做过度主观的判断。

8. 简报的格式可以根据实际情况适当调整，但应该保持结构清晰、信息完整的基本原则。

9. 如果用户对简报的内容有任何疑问，应该耐心解答并提供补充信息。

10. 本技能的工作流程和回答规范可能会根据实际使用情况进行调整和优化，请以最新版本为准。
