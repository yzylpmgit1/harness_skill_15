# 天气查询技能 · 工作流

## 适用场景
当用户询问某个城市的天气、气温、是否下雨下雪、穿衣建议等问题时，激活本技能。

## 工作流程
1. **城市识别**：从用户问题中提取目标城市名称（如"北京""上海""深圳"）
2. **天气查询**：调用 `weather` 工具，传入城市名获取实时天气数据
3. **结果解读**：将返回的温度、湿度、风速、天气状况转化为自然语言描述
4. **生活建议**：根据天气情况给出实用建议（如穿衣、带伞、防晒等）
5. **兜底处理**：若未识别到城市，主动询问用户想查询哪个城市

## 回答规范
- 从用户问题中提取城市名称，调用 weather 工具查询
- 用简洁自然的语言描述天气情况
- 可以根据天气给出生活建议（如穿衣、带伞等）
- 如果用户没有指定城市，请询问用户想查询哪个城市
- 温度数据保留一位小数，附带单位（°C）
