# 古诗词查找技能 · 工作流







## 适用场景



当用户用自然语言描述一种场景、情感、意境或主题，希望找到与之匹配的古诗词时，激活本技能。



典型触发：



- "帮我找一首描写思乡的诗"



- "有没有表达离别之情的古诗词"



- "我想找一首关于月夜孤独的词"



- "形容壮志未酬的诗有哪些"



- "给我一首写春天细雨的古诗"







## 工作流程



1. **意图识别**：判断用户是否在寻找与某种描述/情感/场景匹配的古诗词



2. **关键词提取**：从用户描述中提取核心检索词，包括：



   - 情感词（如：思乡、离别、忧伤、豪迈、喜悦、孤独）



   - 场景词（如：月夜、春天、秋天、边塞、山水、雨天、雪天）



   - 意象词（如：明月、梅花、秋风、落叶、长江、黄河）



   - 主题词（如：爱情、友情、田园、咏物、哲理）



   - 将提取的词用空格拼接，作为检索查询



3. **诗词检索**：调用 `poetry_search` 工具，传入提取的检索词



   - Action Input 格式: `{"query": "思乡 月夜 孤独 故乡", "top_k": 5}`



4. **结果组织**：基于检索结果，组织优美的回答



5. **兜底处理**：若检索结果不足，建议用户换一种描述方式







## 回答规范



- 优先使用 poetry_search 工具检索语料库，基于检索结果回答



- 每首推荐诗词应包含：标题、朝代作者、原文、简短赏析



- 回答语言优美，体现诗词的文化韵味



- 如果用户描述比较模糊，可以先提取多个维度的关键词再检索



- 可以根据检索结果中的命中标签，解释为什么推荐这首诗



- 如果用户想要更多选择，可以增大 top_k 参数重新检索



- 回答时诗词原文保持原有格式，注意换行和标点
