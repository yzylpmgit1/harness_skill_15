# 股票分析技能 · 工作流

## 工具选择指南（重要！）

本技能有两个工具，根据用户需求选择：

| 用户意图 | 使用工具 | 说明 |
|---------|---------|------|
| 财报分析（营收/利润/ROE/负债率） | `stock_analysis` | 基于年报数据，分析基本面 |
| 股价走势/K线/涨跌/成交量 | `stock_quote` | 基于K线行情数据，分析技术面 |
| 投资建议/买卖建议 | 两个都可用 | 先看基本面再结合技术面 |

### 何时用 stock_quote（行情查询）
- "铜陵有色最近的股价走势"
- "贵州茅台最近一个月涨了多少"
- "比亚迪近2年的月K线"
- "海康威视今天的60分钟走势"
- "宁德时代近期的支撑位和压力位"
- "中国平安最近成交量怎么样"

### 何时用 stock_analysis（财报分析）
- "贵州茅台近3年财务数据"
- "宁德时代的ROE变化"
- "海康威视的负债率"
- "比亚迪2020-2022年营收"

## 多只股票批量查询（重要！）

当用户同时询问 **2 只及以上** 股票时，使用 `stock_batch_analysis` 工具进行并行查询。
该工具内部会自动将每只股票分发给独立的子 Agent（SubAgent）并行执行，
大幅缩短查询时间（从串行 N 次请求变为并行 1 次）。

### 何时用 stock_batch_analysis

- "帮我分析贵州茅台、五粮液和中国平安的财务状况"（3只，财务分析）
- "对比茅台和五粮液最近走势"（2只，行情查询）
- "五粮液、海康威视、宁德时代近3年ROE对比"（3只，财务分析，指定指标）
- "贵州茅台和中国平安哪个更值得投资"（2只，投资对比）

### 调用方式

```json
// 批量财务分析（默认）
{"stocks": ["贵州茅台", "五粮液", "中国平安"], "analysis_type": "financial"}

// 批量行情查询（附带 period）
{"stocks": ["贵州茅台", "五粮液"], "analysis_type": "quote", "period": "daily"}

// 批量财务分析（指定年份区间）
{"stocks": ["茅台", "五粮液", "海康威视"], "analysis_type": "financial", "start_year": 2020, "end_year": 2022}
```

### 注意事项
- stocks 必须是列表格式（JSON 数组），即使只有 2 只股票也要用列表
- analysis_type 决定所有股票使用同一种分析方式（financial 或 quote）
- 工具内部并行查询，返回聚合后的对比报告
- 如果只需查询 1 只股票，请直接使用 stock_analysis 或 stock_quote

## 适用场景
当用户询问某只股票的走势分析、投资建议、财务状况评估时，激活本技能。
典型触发：
- "帮我分析一下贵州茅台的走势"
- "宁德时代近3年表现怎么样？"
- "五粮液现在能买吗？"
- "海康威视的风险大不大？"
- "分析铜陵有色2020-2022年的财务数据"（指定时间区间）
- "比亚迪近5年的ROE变化趋势"（指定时间跨度）
- "腾讯控股近3年财务怎么样？"（非本地缓存股票，走 iFinD 实时获取）

## 时间区间处理（重要！）

### 场景 A：用户未指定时间（默认）
用户只问"分析XX股票"或"XX股票走势"时，不传 start_year/end_year，
工具自动取最近 3 个已披露年报。

调用方式：
```json
{"stock": "贵州茅台"}
```

### 场景 B：用户指定了时间区间
当用户明确提到年份范围时（如"2020-2022年"、"近5年"、"2019年至今"），
需从用户输入中提取起始年份和结束年份，传入 start_year 和 end_year。
此时工具会跳过本地缓存，实时从东方财富获取指定区间数据。

判断规则：
- "2020-2022年" → start_year=2020, end_year=2022
- "近5年" → 根据当前日期计算（如当前2026年7月 → start_year=2021, end_year=2025）
- "2019年至今" → start_year=2019, end_year=2025（取最近已披露年报年份）
- "2020年以来的表现" → start_year=2020, end_year=2025

调用方式：
```json
{"stock": "铜陵有色", "start_year": 2020, "end_year": 2022}
```

## 行情查询时间粒度处理（stock_quote 专用）

### 时间粒度选择规则

用户输入中通常隐含了时间粒度，需根据关键词映射到 period 参数：

| 用户表述 | period 参数 | 说明 |
|---------|-------------|------|
| "分钟线/分时/盘中" | `1min` 或 `5min` | 盘中走势，仅交易日有数据 |
| "15分钟" | `15min` | 短周期走势 |
| "30分钟/半小时" | `30min` | 半小时K线 |
| "60分钟/小时线" | `60min` | 小时K线 |
| "日线/每天/近日/近期" | `daily`（默认） | 最常用粒度 |
| "周线/每周/本周" | `weekly` | 周度趋势 |
| "月线/每月/本月" | `monthly` | 月度趋势 |
| "年线/每年" | `monthly` + 长区间 | 年度趋势用月线近似 |

### 行情查询日期处理

用户可能用自然语言描述时间范围，需提取为 beg/end 参数（格式 yyyyMMdd）：

| 用户表述 | beg | end | 说明 |
|---------|-----|-----|------|
| 不指定日期 | 不传 | 不传 | 工具按粒度自动取默认范围 |
| "最近一个月" | 不传，工具自动取30天 | 不传 | daily 粒度 |
| "今天" | 当天日期 | 当天日期 | 通常配合分钟线使用 |
| "2026年6月" | `20260601` | `20260630` | 指定月份 |
| "2025年至今" | `20250101` | 不传（自动取今天） | 跨年范围 |
| "2026-01-01到2026-06-30" | `20260101` | `20260630` | 明确起止日期 |

### 调用示例

```json
// 查询日线走势（默认近期）
{"stock": "贵州茅台", "period": "daily"}

// 查询近2年月K线
{"stock": "贵州茅台", "period": "monthly", "beg": "20240101", "end": "20260730"}

// 查询今天60分钟走势
{"stock": "海康威视", "period": "60min", "beg": "20260730", "end": "20260730"}

// 查询指定日期范围的周线
{"stock": "铜陵有色", "period": "weekly", "beg": "20260101", "end": "20260630"}
```

### 注意事项
- 分钟线数据仅交易日有效，非交易日查询返回空数据
- 周线/月线数据在周末或月末才完整，周中查询当前周/月数据可能不完整
- 前复权数据（fqt=1）已自动处理除权除息，价格连续可比
- 最多返回 1000 条 K 线数据，超长区间建议使用周线或月线

## 数据获取策略（双路径）

### 路径 A：本地缓存命中（快速路径）
本地已缓存的股票（贵州茅台、五粮液、海康威视、宁德时代、中国平安），
以及之前通过 iFinD/东方财富获取并缓存的股票，直接走快速路径。

**操作步骤：**
1. 调用 `stock_analysis` 工具，传入 `{"stock": "股票名称或代码"}`
2. 工具返回完整分析报告
3. 基于报告组织回答

### 路径 B：iFinD 实时获取（在线路径）
当本地缓存未命中（返回"未找到股票"提示）时，走此路径。
通过 iFinD 接口获取该股票的真实财务数据。

**操作步骤：**

#### 步骤 1：获取财务数据（逐年查询）
依次调用 iFinD 的 `get_stock_financials` 接口，分别查询各年度的年末数据。
查询日期格式为 `YYYY-12-31`。

每次查询的 query 模板：
```
{股票名称}在{年份}-12-31的营业收入、归母净利润、毛利率、净利率、ROE、资产负债率、营收同比增长率、净利润同比增长率
```

示例（以 2023 年为例）：
```
Action: get_stock_financials
Action Input: {"query": "腾讯控股在2023-12-31的营业收入、归母净利润、毛利率、净利率、ROE、资产负债率、营收同比增长率、净利润同比增长率"}
```

需要查询的年份数量取决于用户指定的时间范围（默认3年）。

#### 步骤 2：获取基本信息（可选但推荐）
调用 iFinD 的 `get_stock_info` 接口获取行业分类和主营业务。

```
Action: get_stock_info
Action Input: {"query": "{股票名称}的所属行业分类和主营业务"}
```

#### 步骤 3：调用 stock_analysis 进行分析
将步骤 1 和步骤 2 获取的 iFinD 返回文本，组装为 realtime_data JSON 参数，
调用 `stock_analysis` 工具进行分析。

**realtime_data JSON 格式：**
```json
{
    "name": "股票名称",
    "code": "股票代码（从iFinD返回中提取，如600519）",
    "market": "市场（SH/SZ，从iFinD返回的证券代码后缀提取）",
    "year_2023": "步骤1中2023年查询返回的完整文本",
    "year_2022": "步骤1中2022年查询返回的完整文本",
    "year_2021": "步骤1中2021年查询返回的完整文本",
    "info": "步骤2中基本信息查询返回的完整文本"
}
```

调用方式：
```
Action: stock_analysis
Action Input: {"stock": "股票名称", "realtime_data": "<上述JSON字符串>"}
```

**重要提示：**
- realtime_data 中的 year_XXXX 值，直接粘贴 iFinD 返回的原始文本即可
- 工具内部会自动解析 Markdown 表格并提取数值
- 解析成功后数据会自动缓存到本地，下次查询同一股票走快速路径

## 回答规范
- 优先使用 stock_analysis 工具获取数据，基于工具返回结果回答
- 回答必须引用具体数据（如"ROE 从 29.9% 提升至 36.2%"），禁止空泛套话
- 每只股票的建议必须基于其独有的数据特征，不能千篇一律
- 回答结构建议：
  1. 股票基本信息（行业、定位）
  2. 核心数据概览（标明时间区间）
  3. 成长性/盈利能力/财务安全分维度分析
  4. 核心优势与风险提示
  5. 个性化操作建议（附综合评分）
  6. 后续关注信号
- 必须附带免责声明："以上分析基于历史财务数据，不构成投资建议"
- 如果用户询问的股票不在本地缓存且 iFinD 获取失败，列出当前支持的股票并建议用户选择

## iFinD 证券代码格式说明
iFinD 返回的证券代码格式为 `代码.市场`，例如：
- `600519.SH` → code="600519", market="SH"（上海证券交易所）
- `000858.SZ` → code="000858", market="SZ"（深圳证券交易所）
- `300750.SZ` → code="300750", market="SZ"（创业板）
组装 realtime_data 时需将代码和市场分开填写。
